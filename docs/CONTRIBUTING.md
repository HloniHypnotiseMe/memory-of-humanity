# Contributing

The Memory of Humanity is an open-source protocol project.

Contributions may include code, schemas, documentation, historical material, technical knowledge, research, translations, interface work and protocol proposals.

## Contribution principles

### Preserve the source

Do not replace an original contribution with a cleaned-up or AI-generated version. Add a transcription, translation, summary or interpretation as a distinct derived record.

### Make provenance explicit

When adding knowledge, document where it came from whenever possible: contributor, source publication, interview, photograph, recording, archive, document, external evidence or transformation history.

### Keep uncertainty visible

If a date, attribution, location or interpretation is uncertain, represent that uncertainty.

### Treat disagreement as information

Different contributors may remember the same event differently. Do not resolve disagreement merely to make the dataset look cleaner.

### AI-generated work

AI assistance is welcome where it improves preservation or discovery, but generated output must be identifiable as generated or derived material. Human source material must remain recoverable.

## Development direction

Protocol contracts and tests come before large interface features.

A pull request should explain:

- what protocol or behavior changes
- why the change is necessary
- what evidence or use case motivates it
- how compatibility is affected
- what tests cover the change

## Governance

Governance will evolve alongside the protocol. Until formal governance is established, contributors should avoid treating implementation choices as immutable protocol law.
