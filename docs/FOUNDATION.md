# Foundation

## Mission

The Memory of Humanity preserves human memory and practical knowledge as distinct, traceable records.

A person's memory, a story told by a grandparent, an archaeological finding, a newspaper article, and an AI interpretation may concern the same subject while remaining different records with different provenance.

## First-class record families

The protocol is expected to support:

- personal memory
- oral history
- folklore / myth / legend / fiction
- cultural practice
- collective memory
- documentary / historical evidence
- place memory
- object / artefact record
- technical / how-to knowledge
- AI-derived interpretation

The exact schema is intentionally not frozen until protocol contracts are implemented and tested.

## Provenance

Every durable record should be able to answer:

- Who contributed it?
- When was it contributed?
- What source material does it derive from?
- Who supplied or verified an interpretation?
- Has it been translated, transcribed, transformed or summarized?
- What versions existed before this one?
- What permissions govern its use?
- Where did this copy come from?

Provenance must survive export and federation.

## Disagreement

Contradiction is part of the archive. Relationships should be able to express supports, contradicts, elaborates, derives_from, variant_of, translated_from, supersedes and related_to.

Conflicting memories should not be silently merged merely because an automated system considers one more plausible.

## Revision

A correction should create traceable history rather than erase the previous contribution. The system should distinguish original contribution, contributor correction, curator annotation, community annotation, external evidence and AI-derived interpretation.

## Privacy and cultural agency

Memory can be intimate, sensitive or culturally restricted. The protocol must support differentiated access and retention policies, including public, family/community controlled, trusted-custodian, sealed-until-date and contributor-defined retention/deletion policies.

Additional safeguards are required for material involving children, vulnerable people and culturally sensitive knowledge.

## Practical knowledge

How-to knowledge is memory of human capability. A technical record may preserve source publication, author/inventor, publication date, patent identifiers, jurisdictions, legal-status observations, materials, tools, procedures, diagrams, measurements, hazards, historical context, related technologies, reconstruction notes and human verification.

Legal status is metadata, not a legal conclusion.

## AI boundary

AI may assist with OCR, transcription, translation, entity extraction, relationship suggestions, duplicate detection, indexing, summarization, conflict detection and discovery.

AI must not silently rewrite an original memory, remove disagreement, manufacture corroboration, turn uncertainty into certainty, attribute a statement without provenance, or replace contributor voice with generated prose.

The raw record remains the anchor.
